# Frontend

Este directorio contiene el código fuente del cliente de TaskFlow Pro.

## Tecnologías

- React
- Tailwind CSS
- React Router
- i18n para soporte multilenguaje

## Estructura esperada

- `src/` – Archivos fuente de React.
- `public/` – Recursos públicos (HTML, íconos, etc.).
- `i18n/` – Archivos de localización y traducción.

## Instrucciones de desarrollo

```bash
cd frontend
npm install
npm run dev
```
