# 📚 Documentación Técnica – TaskFlow

Este directorio contiene los artefactos técnicos del proyecto **TaskFlow**, incluyendo diagramas arquitectónicos y especificaciones clave que respaldan el desarrollo, mantenimiento y despliegue del sistema.

## 🗂️ Contenido

- `componentDiagram.drawio` – Diagrama de componentes del sistema.
- `taskFlowDbModel.drawio` – Modelo de datos de la base de datos (MongoDB).
- `*.svg` – Versiones exportadas de los diagramas en formato visual (SVG).

## 🎯 Objetivo

Proveer una fuente centralizada y actualizada de documentación técnica que:

- Guíe a desarrolladores actuales y futuros.
- Sirva como referencia en revisiones de arquitectura.
- Facilite el onboarding de nuevos colaboradores.
- Respalde el proceso de despliegue e integración continua.

## 🛠 Herramientas Recomendadas

- [**draw.io**](https://app.diagrams.net) – Para edición y visualización de diagramas `.drawio`.
- [**VS Code**](https://code.visualstudio.com/) con la extensión *Draw.io Integration* – Para edición directa en el editor.
- Navegador web – Para visualizar los `.svg`.
