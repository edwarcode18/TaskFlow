# 🚀 TaskFlow – Gestor de Tareas Avanzado

TaskFlow Pro es una aplicación web moderna para gestionar tareas de forma eficiente. Ideal para equipos pequeños o usuarios individuales que buscan una experiencia fluida, personalizable y multilenguaje.

## 🧩 Tecnologías principales

- **Frontend:** React, Tailwind CSS, i18n
- **Backend:** Node.js, Express.js
- **Base de datos:** MongoDB
- **Autenticación:** JWT
- **Pruebas:** Jest
- **CI/CD:** GitHub Actions
- **Contenedores:** Docker
- **Despliegue:** Google Cloud Platform (Cloud Run o Firebase Hosting)

## 🎯 Características

- ✅ CRUD completo de tareas
- 🔔 Notificaciones asíncronas
- 🌐 Soporte multilenguaje
- 🧪 Validación con middlewares
- 🔐 Autenticación y autorización con JWT
- 📘 Documentación interactiva (Swagger)
- 🚢 Contenedores Docker para facilitar el desarrollo y despliegue
- 🔄 CI/CD con GitHub Actions
